만족도조사 자동 집계 홈페이지
==============================

1. 구성 파일
- index.html
- style.css
- script.js
- template.png : 사용자가 제공한 빈 설문지의 기준 이미지

2. 현재 자동 집계 대상
- 1번 성별
- 2번 강의 운영 만족도 4개 문항
- 3번 강의 내용 만족도 3개 문항
- 4번 향후 듣고 싶은 프로그램 유형
- 5번 자유의견은 자동 OCR하지 않으며 원본 설문에서 확인

3. 빨간색 문구가 바뀌어도 되는 이유
이 프로그램은 강의명이나 강사명 텍스트를 OCR로 읽어 판독하지 않습니다.
제공된 빈 설문지와 작성된 설문지의 '응답 영역' 차이를 비교합니다.
따라서 3번 문항의 빨간색 강의명/강사명이 바뀌더라도 표의 위치가 그대로면
2번/3번 객관식 집계 로직은 그대로 사용할 수 있습니다.

4. 사용 방법
가장 간단한 방법:
- 이 폴더 전체를 같은 위치에 둡니다.
- index.html을 브라우저에서 엽니다.
- JPG/PNG 설문 스캔은 바로 분석할 수 있습니다.
- PDF는 PDF.js 라이브러리가 필요합니다.

5. PDF와 행정망 사용 시 주의
현재 script.js는 PDF를 브라우저 이미지로 변환할 때만
cdnjs의 PDF.js를 불러옵니다.
따라서 행정망에서 cdnjs.cloudflare.com 접속이 막혀 있으면
PDF 업로드 분석은 동작하지 않을 수 있습니다.

그 경우 선택지:
A. 복합기 스캔 형식을 PDF 대신 JPG로 설정
   -> 외부 접속 없이 이 홈페이지에서 바로 처리할 수 있습니다.
B. PDF.js 라이브러리를 내부 폴더에 다운로드해 로컬 방식으로 변경
   -> pdf.min.mjs / pdf.worker.min.mjs 2개 파일을 함께 두고
      script.js의 PDFJS_CDN, PDFJS_WORKER_CDN 주소를 로컬 경로로 변경합니다.

6. 권장 스캔 조건
- A4 세로
- 200~300dpi
- 자동 회전/기울기 보정 사용
- 한 페이지에 설문지 1부
- 볼펜 또는 진한 펜으로 표시
- 표 바깥이 아닌 응답 셀 안쪽에 체크

7. 판독 원리 및 한계
- template.png의 인쇄 상태와 스캔본을 비교합니다.
- 원래 흰색이던 부분에 새로 생긴 어두운 펜 자국을 찾습니다.
- 스캔 위치가 조금 다른 경우 ±10px 자동 위치 보정을 시도합니다.
- 심하게 비뚤어진 스캔, 접힌 종이, 그림자, 연필의 매우 옅은 체크는
  정확도가 낮아질 수 있습니다.
- 검토 화면에서 모든 객관식 응답을 직접 수정할 수 있습니다.

8. 민감도
기본값 0.70%
- 체크를 놓침 -> 수치를 낮춤
- 빈 칸도 체크로 잡음 -> 수치를 높임
실제 작성 설문 10~20부로 테스트해서 적정값을 정하는 것을 권장합니다.

9. 파일 보안
JPG/PNG 방식은 브라우저 내부에서 처리하며 별도 서버에 업로드하지 않습니다.
현재 PDF 방식도 PDF.js 코드만 외부에서 로드하고,
사용자가 선택한 설문 PDF 내용 자체를 서버로 업로드하는 코드는 없습니다.
기관 환경에서는 내부 보안정책을 별도로 확인하세요.

10. 다음 개선 권장
실제 작성된 설문 스캔본 5~10장을 테스트하면
각 응답 셀의 좌표와 판독 임계값을 더 정확하게 조정할 수 있습니다.
