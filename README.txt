Survey Insight — 만족도 조사 결과 분석

사용 순서
1. 한글·Word 등에서 내보낸 텍스트 포함 원본 PDF를 등록합니다.
2. 자동으로 추출된 문항과 선택지를 확인합니다. 원본에 복수응답 여부가 명시되지 않았으면 직접 설정합니다.
3. 문항 추가·삭제, 문항명·선택지 수정, 응답 영역 드래그 설정 후 '이 문항 구조로 저장'을 누릅니다.
4. 해당 원본으로 작성한 스캔 PDF/JPG/PNG를 올립니다.
5. 응답 검토의 원본과 겹쳐 비교 버튼에서 스캔 원본, 기본 양식, 보정된 스캔본, 겹쳐 보기, 검출 표시를 확인합니다. 문항을 선택하면 해당 답변 영역이 확대됩니다.
6. 검토 필요 응답은 원본을 확인하고 답변을 수정한 뒤 검토 완료로 확정합니다.
7. 문항별·프로그램별 집계 결과와 CSV를 확인합니다.

현재 범위
- 한 페이지 원본 설문을 지원합니다. 응답 PDF는 여러 페이지·여러 파일을 지원합니다.
- 정형화된 표·번호 선택지를 추출합니다. 자유로운 배치는 영역 설정 화면에서 수정할 수 있습니다.
- 자유의견은 수동 입력입니다. 손글씨 OCR은 포함하지 않습니다.
- 원본에서 찾은 문항 수에 따라 검토 화면, 개별 통계, CSV 열이 달라집니다.
- 회전·이동·X/Y 크기·기울어짐을 affine 변환으로 정렬합니다. 원근 보정은 구현 범위에 포함되지 않습니다.
- 서로 다른 프로그램에서 실제 문항 내용이나 표 구조가 바뀌면 각 프로그램의 원본을 별도로 등록해야 합니다.
- 표가 맞지 않거나 정렬 품질이 낮으면 자동 판독값을 비우고 검토 대상으로 분류합니다.
- 빈칸에 숫자나 성별을 적은 응답은 선택지의 표시와 구분되므로 수동 검토가 필요할 수 있습니다.
- 검토 대기 설문은 통계에서 제외합니다. 수동 수정 후에는 다시 검토 완료를 눌러 확정합니다.
- 문항 구조를 저장하거나 원본을 변경하면 기존 분석 결과는 초기화됩니다. 필요하면 먼저 CSV를 내려받으세요.
- 양식 이미지와 문항 구조는 IndexedDB에 저장됩니다. 이전 버전의 고정 좌표 설정은 자동으로 재사용하지 않습니다.
- PDF.js와 이미지 디코더는 vendor/에 포함됩니다. 개인정보가 포함된 응답 파일은 서버로 전송하지 않습니다.

개발 검증
실제 첨부 7개 PDF 77페이지를 동일한 engine.js로 실행했습니다. 응답 원본과 표가 다른 3D 프린팅 8페이지는 정렬 실패로 제외했습니다.
회전/이동/독립 배율, 중복 선택 검토, 복수응답, 문항 증감, 미확정 통계 제외를 별도 회귀 검사했습니다.

이미지 비교 보강 (2026-10-07)
- 겹쳐 보기의 스캔본 비중을 0~100% 조정해 표선 정렬을 확인합니다.
- 검출 표시는 판독에 사용한 동일한 추가 잉크 마스크입니다. 빨간 픽셀은 후보이며 확정 응답을 의미하지 않습니다.
- 원본 인쇄 잉크 주변 4px는 제외하고, 회색 배경 보정 및 6픽셀 미만의 고립 잡점 제거를 적용합니다.
- 문항마다 주변 인쇄 위치를 검사하고, 불일치한 문항의 자동 판독값을 비운 뒤 해당 설문을 통계에서 제외합니다.
- 체크와 동그라미, 배경 농도 변화, 잡점, 문항 위치 불일치, 회전/이동/배율 변환을 검사했습니다.
- 실제 77페이지 엔진 재시험: 자동확정 후보 32부, 검토 대기 45부. 다른 표 구조의 8부는 계속 제외했습니다. 이 분류는 전체 정확도를 보증하지 않습니다.

상하·좌우 정렬 보강
- 이동 시작점을 촘촘하게 탐색하고 서로 다른 위치 후보 6개를 각각 보정해 최종 위치를 선택합니다.
- 자동 정렬은 중심 기준 약 ±220px까지 이동을 탐색합니다. 범위 끝에 걸리면 검토 대상으로 표시합니다.
- 원본과 겹쳐 비교에서 좌우·상하 ±250px, 회전 ±5°, 크기 90~110%를 조정할 수 있습니다.
- 미리보기는 통계에 반영하지 않습니다. 위치 적용 · 다시 판독을 눌러 해당 페이지 답변과 검출 표시를 갱신합니다.
- 자동 정렬 위치로 버튼은 미리보기를 되돌립니다. 실제 답변도 되돌리려면 적용 버튼을 누릅니다.
- 적용 후 자유 의견은 유지하고 선택 응답은 다시 판독합니다. 검토 완료를 다시 눌러야 통계에 포함됩니다.
- CSV에 수동 이동, 회전, 크기 보정값을 기록합니다.
- 오른쪽 110px/위 90px, 왼쪽 95px/아래 115px, 오른쪽 150px/아래 80px 변환 시험을 통과했습니다.
