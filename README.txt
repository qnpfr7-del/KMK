만족도조사 자동 집계 홈페이지 v2

변경사항
1. 2번 강의 운영 문항
   - 2-1~2-4를 각각 따로 보여주지 않고 하나의 통합 만족도 통계로 집계합니다.
   - 예: 설문 10부라면 최대 40개 응답을 합산합니다.

2. 3번 강의 만족도
   - 응답 검토 화면에서 각 설문지의 "프로그램명"을 직접 입력합니다.
   - 집계 결과에서는 동일한 프로그램명끼리 자동으로 묶습니다.
   - 각 프로그램별로 3-1, 3-2, 3-3 통계를 각각 표시합니다.

3. 기타 의견 / 건의사항
   - 응답 검토 화면에서 설문지 원본을 보고 직접 입력합니다.
   - 집계 결과에서는 프로그램별로 의견을 모아 표시합니다.

4. CSV
   - 프로그램명과 기타 의견도 CSV에 함께 저장됩니다.

GitHub Pages 적용
- 기존 저장소의 index.html, style.css, script.js를 이 버전으로 교체하세요.
- template.png는 그대로 사용할 수 있습니다.
- Commit changes 후 GitHub Pages에 자동 반영됩니다.
